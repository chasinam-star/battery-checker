# 리튬 배터리 선적 판정 도구

장금상선·흥아라인 SKR/HAS 규정을 기준으로, 화주 MSDS·메일을 넣으면 리튬 배터리 선적 가능 여부를 판정해 주는 웹 도구입니다.

## 사용법
1. 화주 메일/MSDS 내용을 붙여넣거나 MSDS PDF를 끌어다 놓습니다.
2. 「자동 분석하기」를 누릅니다.
3. 자동으로 추출된 값(UN번호, V, mAh, Wh, 제조사 등)을 확인하고, 틀린 값은 고칩니다.
4. 「자사 부킹 / 타사 부킹」 탭을 눌러 각각의 판정 결과를 확인합니다.

## 판정 기준 요약
| UN | 품목 | 자사 부킹 | 타사 부킹 |
|---|---|---|---|
| 3480/3481 | 리튬이온 (위험물) | RF DG (국내 제조사만) | 선적 금지 |
| 3480/3481 SP188 | 셀 20Wh·배터리 100Wh 미만 | NON-DG DRY | NON-DG DRY |
| 3090/3091 | 리튬금속 | 선적 금지 | 선적 금지 |
| 3171 | 배터리 구동 차량/장비 | EV 금지, 그 외 배터리 분리 시 가능 | 선적 금지 |
| 3536 | 배터리 장착 컨테이너 | 선적 금지 | 선적 금지 |

Wh = V × mAh ÷ 1000

## 유의사항
- 이 도구의 결과는 참고용입니다. 위험물 건은 자동승인이 되지 않으니 운항 담당자 승인 후 진행하고, 필요하면 한국해사위험물검사원의 판정을 받으세요.
- 정확한 용량과 중량은 UN 38.3 Test Report를 기준으로 확인하세요.
- 입력한 자료는 브라우저 안에서만 처리되고 외부로 전송되지 않습니다.
- 스캔 이미지로 된 PDF는 글자를 읽을 수 없습니다. 이 경우 내용을 직접 붙여넣으세요.
